# 演示与评审路线

## 不需要设备的复现

先按README执行npm ci、build:device、test和typecheck。测试使用隔离Mock，验证菜单、规格、购物车、算价和确认保护。实际Ink预览需要aix及macOS Chrome，使用configure:mock和verify:ink，不会调用真实写接口。

## 有眼镜与个人授权时

1. 配置自己的Token并安装自己的本地构建；确认眼镜联网。
2. 首页说“乐奇”→“两份巨无霸、一份薯条，到店自取”。如果门店菜单没有同名可售餐品，以真实匹配结果为准。
3. 按键选门店，核对识别数量、规格和批次。需要时说“换一批”或“全部餐品”。
4. 在购物车说“删除第一项”或“清空购物车”，随后唤醒说“撤销删除”；确认数量及规格恢复。
5. 可进入真实只读算价，核对小计及应付金额；不要为了演示执行真实下单。

## 已有证据说明

README的首页和脱敏订单状态图来自原个人工程真机；其余标注Mock的图为实际Ink隔离运行截图。公开配置流程改变了凭证和身份生成方式，本次未将公开版重新装到原作者眼镜，不能声称新账号完整通过。

状态页双击调用关闭能力已有自动化覆盖，但到达系统桌面的独立真机结果仍待明确确认。支付、真实领券、创建及取消订单不作为此次发布自动演示内容。
