# Contributor instructions

This is the public contest source edition, based on application 1.5.52.
Keep personal tokens, generated credentials, application identity, local build artifacts and device reports out of Git. Configuration examples use environment placeholders only. Do not copy artifacts or Git history from the private personal edition.
Keep the native AIUI Page, real MCP contracts and physical confirmation requirements intact. Do not issue live writes during tests. Tests use an isolated Mock gateway; label screenshots and verification accordingly.
Third-party brands and assets retain their owners' rights; MIT applies only to original code. Keep official CONTEST_DECLARATION.md unchanged.
Before publishing run npm run check:public, npm test and npm run typecheck. Do not add personal business data to screenshots or reports.
