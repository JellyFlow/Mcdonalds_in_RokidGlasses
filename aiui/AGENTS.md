# AIUI application

Native full-screen AIUI Page, 480 × 352 design canvas, operated through keys and voice. No touch bindings or TTS. Keep the existing visual design.
Use official MCP tool contracts and real prices; never invent product, coupon or restaurant codes. Address creation, coupon binding, order creation and cancellation require a physical confirmation on the current confirmation screen. Uncertain submissions must be reconciled before any new submission.
credentials.js and agent.json are generated locally from environment variables and ignored by Git. Never publish personal AIX packages or device reports. Browser APIs must be supported by Ink; do not assume DOM support.
